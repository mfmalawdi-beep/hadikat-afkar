تفعيل لوحة الكتابة والاشتراك البريدي

الملفات جاهزة للربط، لكن هذه الصفحة لا تنشئ حسابات أو صلاحيات نيابة عنك. لا تضع مفاتيح API في المقالات أو الكود أو المحادثة.

١. ربط المشروع بـ Netlify

  1. ارفع ملفات المشروع المصدري إلى مستودع GitHub، ويفضل أن يكون خاصاً لحماية المسودات.
  2. في Netlify اختر إضافة مشروع من GitHub وحدد المستودع. تأكد أن الفرع main وأن ملف package.json في جذر المشروع.
  3. أمر البناء: npm run build، مجلد النشر: dist. إذا كان المشروع داخل مجلد فرعي، اجعله Base directory.
  4. لا تستخدم رفع ZIP ثابت فقط: الكتابة والنشر التلقائي يحتاجان ربط Git، والاشتراك يحتاج نشر الوظائف الخلفية.

٢. تفعيل الدخول والتحرير

  1. فعّل خدمة Identity لهذا الموقع في Netlify.
  2. اجعل التسجيل Invite only، لا تترك التسجيل العام مفتوحاً.
  3. فعّل Git Gateway وامنحه الوصول إلى المستودع الصحيح.
  4. ادعُ بريدك فقط من صفحة مستخدمي Identity. افتح الدعوة على عنوان الموقع المنشور وأنشئ كلمة مرور.
  5. ادخل إلى لوحة الإدارة ثم اختر «المقالات» ← «مقال جديد».

احفظه مع خيار «مسودة» أثناء الكتابة. عند الاستعداد عطّل خيار المسودة واحفظ. يُنشئ Decap تعديلاً في GitHub ويبدأ Netlify بناء النسخة الجديدة. انتظر اكتمال النشر ثم حدّث الموقع.

الحسابات المدعوة محرّرون موثوقون؛ لا تدعُ مشتركين بريديين إلى لوحة الإدارة. إذا كان فرع GitHub محمياً ويمنع الكتابة المباشرة، اضبط سياسة الفرع أو استخدم workflow تحريري مناسباً.

صور الغلاف وحقول الترجمة الإنجليزية موجودة في المحرر. الترجمة يدوية واختيارية؛ المقال غير المترجم يبقى عربياً مع تنبيه في الواجهة الإنجليزية.

٣. إعداد Brevo

  1. أنشئ قائمة جهات اتصال لرسالة الحديقة وسجّل رقمها.
  2. وثّق عنوان المُرسل أو نطاق الإرسال في Brevo.
  3. أنشئ وفعّل قالب رسالة تأكيد اشتراك Double Opt-In. يجب أن يكون زر التأكيد مرتبطاً بـ {{ params.DOIurl }}، ثم انسخ رقم القالب.
  4. أنشئ مفتاح API خاصاً بالمشروع. أضفه في Netlify ضمن متغيرات البيئة الخاصة بالـ Functions، لا في GitHub ولا في واجهة المتصفح.
المتغيرالقيمة
BREVO_API_KEYمفتاح Brevo السري
BREVO_LIST_IDرقم القائمة، مثال 3
BREVO_DOI_TEMPLATE_IDرقم قالب التأكيد المفعّل
SITE_URLرابط الموقع الأساسي كاملاً، مثل https://your-site.netlify.app

بعد إضافة المتغيرات أعد نشر المشروع. استخدم نفس النطاق الموجود في SITE_URL، وأعد توجيه أي نطاق بديل إليه. يُرفض الاشتراك من روابط المعاينات والنطاقات غير المطابقة.

لا تبدأ أسماء هذه المتغيرات بـ VITE_؛ فهي أسرار للخادم فقط. لا تشارك قائمة المشتركين في الملفات العامة.

٤. اختبار التشغيل

  • أنشئ مسودة وتأكد أنها لا تظهر للزوار، ثم انشرها واختبر ظهورها.
  • اشترك ببريد تملكه مع تحديد مربع الموافقة، ثم افحص صندوق الوارد والرسائل غير المرغوب فيها.
  • يجب ألا يُضاف البريد إلى القائمة النهائية قبل الضغط على رابط التأكيد.
  • بعد التأكيد تحقق من وجود البريد في قائمة Brevo. جرّب رابط إلغاء الاشتراك عند إرسال حملة تجريبية.
  • إرسال الرسائل الشهرية يتم من Brevo Campaigns. هذا الربط يستقبل المشتركين ولا يرسل حملة شهرية تلقائياً.

حماية الوظيفة: التحقق من النطاق، تحديد 5 طلبات في الدقيقة لكل IP/نطاق على Netlify، والتحقق من البيانات، وحقل لمكافحة الروبوتات. إذا ظهرت إساءة استخدام أضف CAPTCHA. هذه الحماية لا تعوّض مراقبة الحساب والتكاليف.
